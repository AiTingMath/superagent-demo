# superagent-demo

A small demo repository for dsh-superagent: the agent listens for requests here.

## How to run

This repository is a demo target for dsh-superagent; it has no application to build or start locally.

To try it, open a new issue and mention `@AiTingMath` with the change you want.

The agent works on the request in its own session and replies in the same thread, usually with a pull request.
